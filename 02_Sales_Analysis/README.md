# Interactive Sales Performance Dashboard
### Project Overview
Developed a comprehensive sales tracking tool to transform raw transactional data into actionable business insights. This project demonstrates the ability to handle data cleaning, pivot table analysis, and executive-level visualization.
### Features & Tools
* Pivot Tables & Charts: For dynamic data summarization by region, product, and time.
* Slicers & Timelines: Built for user-interactivity, allowing stakeholders to filter data instantly.
* Advanced Formulas: Utilized `CALCULATEDFIELD`, `ADVANCEDFORMATTING`, and `GETPIVOTDATA` for backend automation.
* Insights Report: Includes a detailed summary of sales trends and growth opportunities.
### Business Impact
* Identified top-performing product categories and seasonal sales peaks to evaluate the firms discount strategy, go-to market strategy, and targeted promotions plan.
* Streamlined the reporting process from manual data entry to an automated visual dashboard.
